### Parivar

I built Parivar to help people manage their own health information and coordinate care with family.

It has separate personal and family views, with sharing controlled through explicit permissions. Being the family administrator doesn't automatically give someone access to another adult's health information.

Built with **SwiftUI, Swift, Vapor, and PostgreSQL**.

### Dayweave

An independent hackathon project that connects Gmail, Google Calendar, and Google Sheets to help plan the next day.

I built a Gemini agent that uses tools to read planning context and suggest a focus. The application handles dates, scheduling conflicts, and action validation. Users review the proposed changes before anything is written to Calendar or Sheets.

This is a public example of my work with LLMs, tool calling, Google APIs, OAuth, and automated testing. The demo uses fictional data; the verification record describes the separate live integration checks and their limits.

Built with **TypeScript, React, Vite, Gemini, and Zod**.
